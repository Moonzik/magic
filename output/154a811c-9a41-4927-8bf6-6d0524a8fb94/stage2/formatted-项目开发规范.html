一、产品概述

玄学疗愈 App 是一款面向 20–35 岁年轻女性的自我关怀产品，融合「玄学命理」与「显化疗愈」两大方向，帮助用户在不确定中找回内在安定、希望与行动力。

产品采用「微信小程序 + 手机 App」双端形态，分阶段推进：先做微信小程序快速验证需求，再扩展 iOS + Android 原生 App，最终引入真人咨询师。

二、功能范围

（一）主要功能（优先开发）

1. 许愿显化 + 每日肯定语 + 今日 Tips

  • 用户创建愿望（目标、期限、分类），每日打卡记录显化进度。
  • 每日推送一条基于「愿望 + 命理画像 + 当日流日」生成的肯定语。
  • 每日推送一条「今日 Tips」，分类涵盖情绪、人际、事业、健康等。

2. 定制高能量音乐（Sub）+ 经文

  • 用户按目标（显化什么）、频率（432Hz / 528Hz 等）、时长定制专属 sub 音乐。
  • 支持叠加经文诵读（经文数据库后续提供）。
  • 内置音乐库，按目标与频率分类浏览、试听、收藏。

（二）次要功能（后续开发）

  • 命理分析：八字、紫微斗数（东玄）、星盘（西玄），每日推送注意事项。
  • 塔罗电子抽牌：78 张塔罗牌，多种牌阵，AI 生成牌义解读，每日一牌。

三、技术方案

（一）跨端框架

  • 小程序：微信原生或 uni-app。
  • App：uni-app / Flutter（一套代码多端，成本最低）。

（二）后端与数据

云服务（微信云开发 / 腾讯云 / 阿里云），存储用户、命理、订单数据。

（三）AI 能力

接入大模型 API，生成肯定语、命理 / 塔罗解读、个性化 tips。

（四）排盘算法

八字 / 紫微 / 星盘使用成熟开源库（Python 排盘库、Swiss Ephemeris 星历），无需自研。

（五）音频生成

AI 音乐生成 + TTS（经文诵读）混音，叠加频率与白噪音。

（六）推送

小程序订阅消息 / App 本地通知。

四、设计规范

（一）视觉调性

  • 面向年轻女性疗愈用户，整体温柔治愈风。
  • 配色以柔和暖色为主，弱化玄学的「神秘沉重感」，突出「轻盈、安定、希望」。

（二）信息架构（4 个主 Tab）

Tab内容
首页今日肯定语、今日 Tips、每日一牌、快捷入口
音乐定制 sub、音乐库、经文诵读
命理八字 / 紫微 / 星盘排盘、每日注意事项
我的愿望清单、显化打卡、会员、订单、设置

（三）关键交互原则

  • 许愿与打卡要轻量、有仪式感、可即时获得正向反馈。
  • 音乐播放器支持循环、定时关闭、收藏。

五、商业模式

采用「免费 + 单次付费 + 会员订阅 + 广告 + 邀请奖励」的混合变现。

（一）会员定价

档位价格
月度会员¥12.8–18.8
季度会员¥35–52
年度会员¥98–128

会员权益：全部音乐库、深度命理报告、全部牌阵、免广告（不含高端定制专属 sub）。

（二）单次付费 · 高端定制

  • 定制专属 sub 音乐 ¥19.9–49.9 / 首，深度命理报告 ¥39–99 / 份，特殊牌阵、合盘。
  • 高端定制独立于会员，会员也需单独购买。

（三）邀请奖励（用户增长）

  • 邀请新用户注册即赠免费使用次数（抽牌 / 深度解读 / 音乐试听等）。
  • 被邀请人产生消费后，邀请人获消费返现：起始比例 3%，当邀请人数超过 3 人后，被邀请人之后新产生的消费返现比例提升至 5%（历史已结算部分不追溯补差）。
  • 返现可用于抵扣会员费或余额消费，MVP 阶段暂不开通现金提现。

六、执行步骤（开发路线图）

分四步走：先合规、再小程序、再留存、再原生 App。

（一）阶段 0 · 合规准备（先行）

定位表述、免责声明、隐私政策、内容合规红线（详见第七节）。

（二）阶段 1 · MVP 微信小程序（1–2 个月）

每日肯定语推送 + 定制 sub 音乐 + 每日一牌 + 基础八字 / 星座分析；免费 + 单次付费，验证需求。

（三）阶段 2 · 完善与留存（3–6 个月）

完整命理排盘（紫微）、塔罗多牌阵、会员体系、广告接入、分享裂变。

（四）阶段 3 · 原生 App（6–12 个月）

iOS + Android，账号数据打通；经合规评估后引入真人命理师 / 塔罗师（连麦 / 1v1）。

七、合规红线

  1. 定位表述：整体定位为「文化娱乐 / 心理安抚 / 自我成长」，避免「算命、预测吉凶、改运」等迷信化表述。
  2. 免责声明：所有测算与解读标注「仅供文化娱乐参考，不构成任何医疗 / 投资 / 决策建议」。
  3. 宗教内容：引入经文需关注《互联网宗教信息服务管理办法》，建议以「传统文化诵读」形式呈现。
  4. 广告与功效：不夸大音乐 / 塔罗的「疗效」，不承诺结果。
  5. 真人咨询（后期）：达人资质审核、杜绝诱导高额消费，设置消费上限与退款机制。
  6. 用户数据：出生信息、愿望等属敏感信息，需隐私合规（隐私政策、脱敏存储）。
