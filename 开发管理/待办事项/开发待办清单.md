## 阶段一：主要功能 · 许愿显化 + 每日肯定语 + 今日 Tips

### 1.1 需求细化与设计
- [ ] 明确「许愿」的交互流程：用户创建愿望 → 设置目标/期限 → 绑定每日提醒
- [ ] 明确「显化」的呈现形式：愿望进度、打卡记录、可视化反馈（如成长进度条）
- [ ] 定义「每日肯定语」生成规则：基于愿望 + 命理画像（后期）+ 当日流日
- [ ] 定义「今日 Tips」内容库：分类（情绪、人际、事业、健康等）
- [ ] 设计 UI 规范：配色（温柔治愈风）、字体、卡片样式

### 1.2 功能开发
- [ ] 许愿模块：创建/编辑/删除愿望，愿望分类与标签
- [ ] 显化打卡：每日签到，记录显化进度
- [ ] 肯定语模块：每日推送 + 手动刷新 + 收藏
- [ ] 今日 Tips 模块：每日一条 + 历史回顾
- [ ] 推送通知：小程序订阅消息 / App 本地通知，支持自定义时段

### 1.3 数据与内容
- [ ] 肯定语内容库：首批 ≥ 100 条（按主题分类）
- [ ] Tips 内容库：首批 ≥ 50 条
- [ ] 用户数据结构：愿望、打卡记录、偏好设置

## 阶段二：主要功能 · 定制高能量音乐（Sub）+ 经文

### 2.1 需求细化与设计
- [ ] 明确「定制 sub」的定制维度：目标（显化什么）、频率、时长、是否叠加经文
- [ ] 定义音乐库分类：按目标（爱情/财富/健康/内在平静等）、按频率（432Hz/528Hz 等）
- [ ] 明确经文内容来源与呈现方式（待用户提供经文数据库）
- [ ] 设计音频播放器 UI：播放/暂停、循环、定时关闭、收藏

### 2.2 功能开发
- [ ] 音乐库：分类浏览、搜索、试听
- [ ] 定制流程：选择目标 → 选择频率 → 叠加经文 → 生成/下单
- [ ] 音频生成：AI 音乐生成 + TTS（经文诵读）混音 + 白噪音叠加
- [ ] 播放器：基础播放控制、定时、后台播放（App）
- [ ] 定制记录：历史订单、我的音乐收藏

### 2.3 数据与内容
- [ ] 音乐库基础曲目：首批 ≥ 20 首
- [ ] 经文数据库结构设计（待用户提供格式与体量）
- [ ] 定制模板：预设 3-5 套常用「目标+频率」组合
